The advert this site is built from

Everything here exists to answer one document. It is worth keeping it in view, because it is also the checklist an interviewer will work through.

Requisiti
  • Laurea o Diploma in ambito informatico o equivalente
  • Da 1 a 3 anni nello sviluppo di applicazioni in ambito .NET
  • Buona esperienza nello sviluppo con framework .NET / .NET Core
  • Ottima conoscenza del linguaggio C# e familiarità con la programmazione ad oggetti (OOP)
  • Buona conoscenza di T-SQL e dei principali RDBMS (in particolare SQL Server)
  • Comprensione dei principi REST e sviluppo di Web API
  • Utilizzo fluido di Visual Studio e/o VS Code
  • Buone capacità di analisi e autonomia decisionale nel proprio dominio
  • Spiccato orientamento al team working e buone doti comunicative
A completamento del profilo
  • ASP.NET Core MVC ed Entity Framework Core
  • Servizi Cloud (Azure) e strumenti di CI/CD (Azure DevOps)
  • Tecnologie frontend di base (HTML, JavaScript, TypeScript)
  • Sistemi di ricerca e caching (ElasticSearch/OpenSearch, Redis)
  • Git per il controllo di versione

The shape of the job, in one picture

Almost every requirement in that advert is one layer of a single request travelling through a system. Learning them in isolation is what makes them feel like twelve unrelated subjects. They are not. They are floors of one building.

🧒 Simple

Imagine a restaurant. The browser is the customer. ASP.NET Core is the waiter who takes the order and checks it makes sense. Your C# is the chef who decides what to actually cook. EF Core is the kitchen porter who runs to the store cupboard. SQL Server is the cupboard — the only place food is really kept. Redis is the small shelf by the stove with things you already prepared. Git is the recipe book where every change is written down, and Azure is the building the restaurant is in.

🎓 Professional

The advert describes a standard layered enterprise stack: a server-rendered or SPA client over an ASP.NET Core HTTP boundary, an application layer in C#, an ORM mapping to a relational store, and two auxiliary data systems — a cache and a search index — that exist because a relational database is bad at exactly two things: repeating cheap answers, and free-text relevance. Everything else in the list (Git, Visual Studio, Azure, Azure DevOps) is the delivery pipeline around it. If you can draw this diagram from memory and say what each arrow costs, you can hold a conversation about any layer in it.

Beyond the advert

The advert above is one company. These twenty-four chapters are not in it — they are here because the same skills turn up again and again in .NET adverts across Modena, Bologna, Reggio Emilia and Milano, and because interviewers ask about them whether the posting mentioned them or not. Three of them — the WinForms/WPF estate, industrial software and Business Central — are whole regional job markets that almost no candidate prepares for, and three more are the rounds you have to pass before anyone reads your code at all.
